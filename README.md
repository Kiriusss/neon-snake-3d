# SNAKE / 3D · 霓虹贪吃蛇

**在线试玩：https://kiriusss.github.io/neon-snake-3d/**

经典贪吃蛇，进入第三维度。使用 Three.js 和原生 JavaScript 制作，无需安装依赖或构建。

- 真正的 3D 棋盘、光照、阴影和收集粒子。
- 立体 / 俯视视角切换。
- 悠闲、经典、极速三档速度。
- 键盘、触屏滑动和手机方向按钮。
- 可选音效、本机最高分、离开页面自动暂停。

## 操作

| 操作 | 按键 |
| --- | --- |
| 控制方向 | 方向键 / WASD |
| 开始、暂停、继续 | 空格 |
| 重新开始 | R |

手机上可以在棋盘滑动，或点击棋盘下方的方向按钮。

每颗橙色能量获得 10 分并增加一格长度。撞墙或撞到自己时结束，填满棋盘获胜。游戏前可选择速度；每收集 5 颗能量会略微加速。

## 本地运行

在项目根目录运行：

```sh
python -m http.server 4321 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:4321 。需要支持 WebGL 2 的现代浏览器。请通过本地 HTTP 服务运行，避免直接双击 HTML 造成模块加载失败。

## 测试

```sh
npm test
```

9 项测试覆盖增长和计分、连续转向、防止掉头、碰撞、尾格让行、满盘胜利和暂停重置。未进行浏览器或手机实机测试，试玩由使用者自行完成。

## 文件

- `index.html` / `style.css`：界面与响应式样式。
- `app.js`：3D 场景、交互和音效。
- `engine.js`：独立游戏规则。
- `engine.test.mjs`：游戏逻辑测试。
- `vendor/`：Three.js 及其 MIT 许可证。

最高分仅保存在当前浏览器，不上传到服务器。第三方资源已包含在仓库中，页面无需连接外部 CDN。

Three.js 许可见 [`vendor/THREE-LICENSE.txt`](vendor/THREE-LICENSE.txt)。
